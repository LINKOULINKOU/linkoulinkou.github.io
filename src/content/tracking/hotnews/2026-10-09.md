## 本期主线：执行边界加固

三处推进指向同一方向：代理「能做什么、不能做什么」的执行边界正在被两层加固。产品侧，Claude Code 把钩子失败时的默认行为从「放行」改为可选「阻断」、并修一批隔离与守卫漏洞（条目 1）；Codex 用一批修复收紧跨平台沙箱（条目 2）。构件侧，作为 Copilot 本地沙箱底层的 MxC 以 v1.0.0 开源为通用 SDK（条目 3）。综合判断：执行边界正从各家产品特性，沉淀为更明确的语义与可复用的基础设施。

### 1. Claude Code 2.1.294–295：钩子漏拦修复与「失败即阻断」选项

两天之内两版：2.1.294（10-08 午后）修复两处钩子判定问题——**以自然语言指令写成的「指令型钩子」此前会放行本应拦截的动作**（钩子：在固定环节自动执行或拦停动作的挂载点，指令型即用自然语言描述规则）；并改进停止类钩子的判定以减少过早收工。2.1.295（北京时间 10-09 凌晨）体量更大：新增「钩子失败即阻断（fail-closed）」选项——钩子无法启动、超时或异常退出时，从默认放行改为阻断该动作；Mods（插件扩展机制）增加原生通知与按钮子元素能力；批量修复集中在三处：子代理隔离（在自身工作树中不再被展示父会话的 git 状态）、Mods 守卫绕过路径（重载期间的调用绕过另一 mod 守卫、守卫收到被截断输入时不报错放行）、远程 MCP（模型上下文协议，用统一接口连接外部工具与数据）连接的重连退避与分页问题。

对本工作流：如果你用钩子做护栏，2.1.294 之前「指令型护栏」可能一直在漏拦——升级后务必复测；需要更硬的护栏时，再显式开启失败即阻断。注意发行渠道：截至核对，npm 上 latest/next 为 2.1.295，而 stable 标签仍停在 2.1.286（滞后 9 个补丁版），按渠道确认你拿到哪一版。

### 2. Codex CLI 0.162.0：沙箱安全修复与托管 Git 工作树

稳定版 0.162.0（10-08 傍晚）承接 0.162 预览线转正，两条与权限/沙箱直接相关：修复 Linux 沙箱在多个拒绝文件下的启动、拒绝可写的「沙箱构建用可执行文件」、防止 ripgrep 配置削弱拒绝通配掩码；恢复 Windows 10 的常规盘符文件访问并对齐沙箱临时目录权限。功能侧新增：为可信本地项目创建与列举托管 Git 工作树（worktree，同一仓库的并行检出目录）的工具、Code Mode 增加流式结果助手与可选的排序工具检索、自定义模型提供方可配置实时联网访问与远程压缩。另有「经批准的旧版发行不会覆盖新版下载目标」与签名版 PowerShell 安装器等发布纪律项。0.163.0-alpha 已开线但无说明，不列。

### 3. 微软开源 MxC SDK v1.0.0：代理沙箱沉淀为跨平台构件

Microsoft eXecution Container 的 SDK 于 10-07 发布 v1.0.0 稳定版（MIT 许可）：一套可嵌入应用与代理框架的沙箱执行库，跨 Windows/macOS/Linux，统一文件系统/网络/界面策略模型，后端覆盖进程容器、系统沙箱、LXC、bubblewrap、Seatbelt 到 MicroVM，提供 Rust/.NET/Node 绑定。此前它已作为 Copilot 本地沙箱（10-07 转正，见 10-08 期条目 1）的底层；现在以独立开源库供任何代理项目复用。社区端传播明显：Simon Willison 称其「很有前景」，仓库 10-08 仍处活跃提交。

对自建 harness（代理运行框架）：跨平台沙箱不必再从零造——评估「本机代理跑在什么边界内」时多了一个官方维护的构件选项。

边界：v1.0.0 为稳定化节点（此前 0.6–0.9 为预览线）；「转公开」的确切时点因 web.archive 不可用未核定；星标与点赞为 10-08/09 快照。
