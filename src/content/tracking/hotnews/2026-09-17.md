## 本期重点：面向自动化决策的「系统一模型」新品类

两年来「模型聊天超人类、自动化却没发生」之问得到了一个新品类答案：TypeSafe AI 9/15 发布 System One Models 与首个模型 Jev（HN 1693 分，本窗口最大社区事件）。它不做字符串生成，输入非结构化状态、输出带校准概率的类型化决策——作者将其定位为「前沿智能版 function call」，与本期已有的两条线相接：权限与出站控制讨论的是「如何约束 agent 决策」，而 Jev 类模型声称从模型层消灭决策层的幻觉与类型错误。综合判断：这是对 harness 决策层（路由、分类、工具选择、审批判断）的直击，但全部效果数字为自建基准自报（作者自己注明基准「为让模型好看而构造」、参考答案取 Astra 与 Fable 均值），未独立验证——按新品类发布对待，不按已证性能对待。

### 1. TypeSafe AI 发布 System One Models 与 Jev：结构化决策专用 + RLCD

**发生了什么**：Diogo Almeida（ex-OpenAI，ChatGPT 指令跟随研究背景）两年隐身后发布：新模型架构 + 并行采样器 + 自研训练法 RLCD（Reinforcement Learning for Calibrated Decisions，为校准决策的强化学习）。Jev 放弃字符串生成，换取结构化输出、每次输出附置信度、同类输入答案一致，官方称在同任务智能相近下比现有 LLM 快两个数量级；自建基准中「独占 Pareto 前沿近两个数量级」（对比对象是被 wrapper 强制结构化输出的 LLM，含 GPT-6 Astra 与 Fable 5.1）。Jev 即日开放早期访问（waitlist）。

**影响与判断**：若校准概率可信，agent 栈里的决策点（工具选择、审批、路由）可以换成低延迟专用模型——与本周 Real-SWE 的「分层用模」思路同向。边界：所有数字自报；「不能幻觉」是对输出类型的保证（schema 匹配），不是语义正确性保证；基准为自建且作者自认有偏。等第三方复测再定性能结论。

来源：[Introducing System One Models & Jev](https://typesafe.ai/blog/introducing-system-one-models-and-jev)｜TypeSafe AI（Diogo Almeida）｜2026-09-15｜A（发布事实）/自报数字（效果）；[HN](https://news.ycombinator.com/item?id=49717558)（1693 分）｜C

## 其他值得关注

### 2. GPT-5.5 定档 10 月 14 日退役；Codex 用户迁 gpt-5.6-sol

官方 changelog 9/14 新条目：GPT-5.5 于 10/14 从 ChatGPT、ChatGPT Work、Codex 全线退役（含消费/Business/Enterprise/Edu），**不适用于 OpenAI API**（X 官宣帖补充：API 平台与 API-key 认证的 Codex 会话不受影响）；ChatGPT 登录的 Codex 用户在退役前从 gpt-5.5 切到 gpt-5.6-sol，并需更新工作区默认、保存的模型设置、托管配置、自定义 agents、定时任务与仍选择 gpt-5.5 的脚本。OpenAIDevs 9/15 连发推文扩散。

**影响与判断**：模型生命周期管理的第三轮（此前 GPT-5.4 系已限时迁移）——自定义 agent、定时任务里的模型名是隐性配置债，退役公告是显式清单。来源：[GPT-5.5 retirement（changelog）](https://learn.chatgpt.com/docs/changelog)｜OpenAI 官方｜2026-09-14｜A；[@OpenAIDevs 推文](https://x.com/OpenAIDevs/status/2099954342170067174)｜A

### 3. Claude Code v2.1.273：权限检查器两处逃逸修复与远程会话分叉

v2.1.273（9/16 凌晨）：修复权限检查器无法完全分析的 Bash 命令在 `permissions.blockReadsOutsideWorkingDirectories` 下跳过确认、以及子 shell 在 bypass 模式下藏危险 `rm` 的两处逃逸；Remote Control 会话可从 Claude 应用分叉为后台会话；新增 MCP 服务断连提醒；修复组织关闭 Skills 后 claude.ai 同步技能仍可用（改为进可恢复回收站）、MDM 托管的 MCP 限制被忽略、网关凭据错误提示不指名等问题；另增 LLM 网关提示头（opt-in）。

**影响与判断**：权限逃逸修复与本周安全主线（deny 名单被绕、蜜罐作弊）同向；「子 shell 藏 rm」提醒 bypass 模式的审批面比表面宽。v2.1.271/272 见上期条目 3。来源：[v2.1.273](https://github.com/anthropics/claude-code/releases/tag/v2.1.273)｜Anthropic 官方｜2026-09-16（UTC）｜A

### 5. Dream-RSI：不改 agent、只改编排层的递归自我改进框架

arXiv 2609.14858（9/14 提交，HN 93 分）：Google 主导（+DeepMind/UMD/UVA）的可扩展、递归自我改进探索框架——轻量编排层把探索显式化、可编程化，底层 coding agent 与评测器保持不变；核心洞察是「已完成的发现树 = 已到达搜索空间的精确重放模拟器」，新策略用零执行「做梦」离线评估后再上线。三域八任务自报改进（见专题稿）。

**影响与判断**：这是「循环工程」（编排层持续触发并验证 agent）的学术化样本——但注意它是探索策略（元层）的 RSI，不是模型权重自我改进；全部数字自报、代码未发布。边界：karpathy 09-12 帖与该论文的关系**未证实**（帖不可读且早于 arXiv 两天），本稿不作关联陈述。机制细节、对照设计与发布状态见专题稿 [2026-09-17-专题-dream-rsi-编排层递归自我改进](/tracking/2026-09-17-dream-rsi-编排层递归自我改进)。来源：[Dream-RSI](https://arxiv.org/abs/2609.14858)｜arXiv｜2026-09-14｜A（摘要级）
