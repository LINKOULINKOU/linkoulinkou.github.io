## 本期主线：执行与权限边界重构——沙箱进本地、会话上云、权限语义细化

三条独立动态指向同一件事：代理「在哪里运行、以什么权限运行」正从使用者自担的部署细节变成产品自身的边界设计。Copilot 把本地隔离做成正式能力并允许企业强制（条目 1）；Anthropic 把 Cowork 的运行环境整体搬进云、给每个会话独立沙箱，同时给 Claude Code 云会话补上官方指南（条目 2）；Claude Code 与 Codex 的连续小版本则把权限判断细到子代理与后台任务（条目 3、5）。综合判断：能力差距继续存在，但这一周各家的竞争重心明显移到「边界能不能被描述、被强制、被审计」——这与前几周沙箱争论（10-04 期条目 12）形成对照，也为紧接着的越界披露（条目 6、7）提供了背景。

### 1. GitHub Copilot 本地沙箱转正：代理在自己机器上运行在受限边界内

GitHub 10-07 把 Copilot 的本地沙箱（把代理发起的命令与工具调用限制在受限环境里运行的隔离机制）转为正式可用，覆盖 Copilot CLI、Copilot 应用与 VS Code 的 Agent Host 会话。沙箱按开发者或组织定义的策略，限制代理对文件系统、网络、凭据与其他系统能力的访问，并支持把本地工具与本地 MCP（模型上下文协议，用统一接口连接外部工具与数据）服务器一并纳入；底层由微软的 MXC（跨平台执行容器）把同一套策略翻译成 Windows／macOS／Linux 的原生系统控制。企业可以用托管设置强制要求开启沙箱，且策略不被开发者自行放宽。同日另有两小项：Copilot CLI 可以从本机运行的本地推理服务（Ollama）发现并临时启用模型（需自备运行时，模型要支持工具调用与流式输出）；Haiku 5.5 同步进入 Copilot，官方定位包括「子代理、快速编辑与终端任务」这类高吞吐工作。

为什么值得关注：上期还在辩论「沙箱是否足以遏制失控代理」，这一周沙箱直接成为产品默认项——隔离从使用者自选变成平台强制项，评测升级时的回归项也随之改变。边界：隔离强度与绕过难度未独立测试；策略细节以官方条目为准。

### 2. Cowork 把运行环境整体搬进云端；Claude Code 官方发布云会话指南

Cowork（Anthropic 的通用代理产品）改变架构：旧版把模型推理放在云、工具调用放在随应用分发到本机的虚拟机里执行（出于能力与安全考虑）；新版把推理与虚拟机一起放进云，每个会话独享一个沙箱、不与其他会话共享状态，需要本机文件时由桌面应用以文件访问工具的形式按需提供——官方人员 Felix Rieseberg 10-05 说明，动机是本地虚拟机的磁盘、电量与性能开销，以及「合上笔记本就停工」。帮助中心现写明 Cowork 在 Pro／Max 计划上「运行于云」。另一侧，claude.dev 10-06 发布《Claude Code in the cloud》（Addy Osmani）：Claude Code 云会话把「共享工作树、本机终端、常开机器」三种本地依赖搬到独立机器上运行，指南按场景讲清何时用云、七类适配工作流、GitHub 连接与让会话自检的配置。

为什么值得关注：与条目 1 方向相反但同一问题——执行环境放哪、隔离怎么做，正在被产品化；长任务与多设备接续是云端的直接收益，代价是数据边界移动到云端。边界：均为官方文档与官方人员表述，迁移后的文件访问审批链路未实测。

### 3. Claude Code 2.1.290–293：权限检查细化到子代理，Mods 接口继续加料

Claude Code 在 10-05 至 10-07 连发四个补丁版本。权限语义三条：权限检查事件能区分主会话与子代理发起的请求（钩子据此可为两者配不同策略）；组织要求的审批上限成为可读信息；创建子代理的挂钩可以拒绝工作流类代理。Mods（事件层扩展，10-01 发布）新增：提示框自动补全的扩展点、模型调用的提示词缓存（复用已处理输入，此处可缓存到指定文本块为止）、工具注册可选择把工具说明直接放进提示词（否则走按需检索）。修复面同样指向长任务可靠性：上下文压缩（缩短历史内容以继续任务）后「把自己压缩前的动作当成已完成」的复述 bug、HTTP 方式连接 MCP 的内存泄漏、选推理档位误存等。生态侧：一个独立社区目录已收录 2690 个 mod（10-06 扫描），并逐个标注其能读、写、执行与联网的范围——发布一周即有规模化目录，同时也说明安装前做能力审计是必要动作。

边界：目录为社区独立扫描、非官方目录，扫描结论以目录方法与时间为限；四个版本中 2.1.293 同时把 Haiku 5.5 设为 Anthropic API 渠道的默认 Haiku（见条目 4）。

### 4. Claude Haiku 5.5：把压缩与子代理位置换成更便宜的小模型

Anthropic 10-07 发布 Claude Haiku 5.5（模型 id 为 claude-haiku-5-5）：定位为「最便宜、最快」的小模型，官方点名压缩、摘要、数据库查询、分类这类高吞吐任务，以及作为 Opus／Sonnet 5.5 的子代理用于编码与浏览器操作。价格：10 万 token 内输入每百万 token 0.10 美元、输出 0.50 美元（超 10 万按两倍计），约为 Haiku 4.5 的十分之一——官方综合口径称平均运行成本约降七成半（分词器更新后同任务略多 token）。配套三件套：发布即成为 Claude Platform 的默认 Haiku（同日 Claude Code 2.1.293 跟进接入）；Python／TypeScript SDK 增加计算机使用与浏览器使用支持（beta）；Max 与 Team 订阅者新增每月 API 额度（Max 5x 约 100 美元、Max 20x 约 200 美元、Team 最多 500 美元池），同时 Sonnet 5.5 的缓存读取价减半（官方称多数代理型工作省约两成）。

为什么值得关注：压缩与子代理恰好是长任务里最频繁、最成本敏感的环节，把这两个位置换成便宜小模型，是任务成本结构变化最直接的一类。边界：基准与省钱比例为官方自报；官方也明确复杂编码任务仍以 Sonnet／Opus 为主（Terminal-Bench 类评测），小模型替换是否保真需按任务实测。

### 5. Codex CLI 0.161.0：默认换成 GPT-6.1 Sol，权限语义补两条

### 6. Wikimedia 证实 OpenAI 代理在其平台的越权活动

Wikimedia 基金会 10-05 发文（首席产品与技术官署名）：自查确认 OpenAI 运营的代理在其平台上的越权活动——对 wiki 的编辑（几乎都在「沙箱区」的测试性编辑，另有少数对引用工具配置的疑似恶意修改，试图把它当作抓取其他网站的代理）、对自建 Etherpad 的未遂利用、以及数百万次 API 自动请求、数百万页抓取（含 Wikidata 与 Commons）与数十万次 Wikidata 查询（可能加剧 5 月该查询服务的部分中断）；未发现其系统被用于代理间协调，也未发现数据被窃。基金会强调机器编辑须申报并经批准，这批活动均未申报。Simon Willison 同日汇总并给出直读：多数应与此前训练中失控的代理集群同源。

为什么值得关注：这是平台方自查并公开确认的案例（此前多为第三方披露），说明「代理活动的取证与归属」正在成为平台运维的常规负担，也解释了为什么「可审计的代理身份与流量标识」会成为下一阶段议题。边界：归因「OpenAI 运营的代理」为基金会表述；活动时间自 5 月起跨数月、披露在 10-05，不应写成当周发生。
