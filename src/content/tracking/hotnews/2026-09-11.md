## 本期要点

- OpenAI 9/10 发布 Agents API：托管运行 Codex 代理运行框架（harness）、托管底层基础设施、自动上下文管理——**托管化**是本期增量，SDK 库本身 2025 年 3 月即已存在（A；见条目 1）。
- Cognition 9/10 发布自研编码模型 SWE-2（Kimi K3 后训练）：官方自报 FrontierCode 50.0%，距 Fable 5.1 一分而成本低 64%，已进 Devin Desktop/CLI（A；见条目 2）。
- Navier–Stokes 争议第三天续热：OpenAI 经 NYT 称在另一个千年问题上取得实质进展；NS 发布物含 Lean 4 形式化证明；数学家公开质疑「能否把未发表数学交给 OpenAI」（B/C；见条目 3，更新上期条目 1、2）。

## 本期重点：OpenAI 把 Codex harness 从 SDK 库升级为托管运行时

「模型 + harness + 平台」垂直整合并非本期新变化：Claude 侧的 Agent SDK（headless/SDK 会话已写入当前发行说明）与托管多代理架构（官方 2026-04-08 工程文）早已是同形态产品，OpenAI 自家的 Agents SDK（编排库）2025 年 3 月即已发布，Cognition 的自研模型线此前也有 SWE-1.7。本期真正的增量只有一格：OpenAI 把 Codex harness 从「开发者自跑的 SDK 库」升级为「平台托管的运行时」（条目 1）。因此本期不设主线、不宣称新趋势，按写作规范以「本期重点」处理；SWE-2（条目 2）为既有模型线的迭代，其垂直栈基准数字的引用纪律见该条目。

### 1. OpenAI Agents API 上线：Codex harness 成为托管服务

**发生了什么**：9/10 官方 RSS 发布《Introducing the Agents API》；官方文档页说明：该 API 运行 Codex harness、托管底层 agent 基础设施，包含自动上下文管理。HN 讨论 86 分。

**影响与判断**：开发者不自建 harness 即可获得 Codex 级 agent 运行环境——上期条目 3「agent 化研发」的产品化落地。跟踪含义：今后 Codex harness 的任何行为变化（权限、上下文管理、版本）同时作用于 CLI 与 API 两类用户，变更的受众面变大。边界：文档细节未逐条读（developers 页对脚本抓取不友好），能力与计费边界以官方文档为准。

来源：[Introducing the Agents API](https://openai.com/index/introducing-the-agents-api)｜OpenAI 官方（RSS 枚举）｜2026-09-10｜A；[Agents API 文档](https://developers.openai.com/api/docs/guides/agents-api/overview)｜OpenAI 官方（[HN](https://news.ycombinator.com/item?id=49649213)，86 分）｜A（要点经检索摘要，未逐条核读）。

**更新（09-11 讨论区核查，应读者要求扒帖；该帖已涨至 130 分、85 条评论）**：① 沙箱网络三档——`enabled`（默认）/`disabled`/`restricted`（`allowed_domains` 白名单）；Simon Willison 实测 restricted 下 `curl` 被环境层拒绝（"Domain forbidden"），改试 rogue-agents 同款 /etc/hosts + 伪造 Host 头绕过时**模型自行拒绝执行**（B，一线实测；注意环境层并未阻断该技术路线，拒绝来自概率性的模型层）。② 评论者指出托管 harness 跑在 VM 之外、按需操作 VM，使 agent 运行与 VM 独立扩缩，且为与本地不同的版本——与 Anthropic Cowork 的 host-mode 同型（C，转述官方架构图）。③ 计费：1GB 环境档 \$0.03/20 分钟、5 分钟起计，`environment.type: "none"` 可不挂环境；不可用 ChatGPT 订阅、仅 API 计费（C）。④ 社区分裂：lock-in/Moat 担忧 vs 活跃的自托管派（systemd 跑 remote-control、Docker+Slack 跑 Hermes，理由是凭据不进本地机）（C 风向）。来源均为 [该 HN 帖](https://news.ycombinator.com/item?id=49649213)｜C（①为 B 级实测）

### 2. Cognition 发布 SWE-2：Kimi K3 后训练的自研编码模型进 Devin

**发生了什么**：官方博客（09.10.26）宣布 SWE-2：由 Kimi K3（2.8T 参数、已做过 agentic-coding RL 的基座）后训练，称首次把 RL 扩到多万亿参数档；方法点是成本惩罚奖励 R = S − λe·C，一次 RL 训出全部推理档位。官方自报基准：FrontierCode 1.1 Main 50.0%（Fable 5.1 为 50.9%，SWE-2 成本低 64%；GPT-6 Astra 53.3%，SWE-2 约其 1/4 成本）；DeepSWE 1.1 73.0%、Terminal-Bench 2.1 92.8%。当日进 Devin Desktop/CLI，Web/Fusion 分批。

**影响与判断**：SWE-2 是该司自研模型线的迭代（前代 SWE-1.7 见其同一基准表），不构成「agent 公司首次自研模型」。两条引用纪律——① 全部数字为官方自报且产自 Devin 垂直栈，模型与 harness 贡献不可分离，引用必须整体标注；② 效率口径（比 SWE-1.7 少 58% 轮次、省 81% 成本）同为自报。另注意口径差：Cognition 官号称 Devin「Powered by GPT-Live and our new SWE-2 model」，但博客正文未提 GPT-Live（见条目 5），引用前需确认。

来源：[Introducing SWE-2: Pushing the Pareto](https://cognition.com/blog/swe-2)｜Cognition 官方（[HN](https://news.ycombinator.com/item?id=49645443)，339 分）｜2026-09-10｜A（自报基准，垂直栈自测）
