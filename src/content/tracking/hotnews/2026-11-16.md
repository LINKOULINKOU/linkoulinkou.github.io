这一期最实的一条是 Code Mode 的说明书终于公开：模型不再逐条发起工具调用，而是写一段 JavaScript 一次跑完，权限检查落到每次调用与整段代码上。另有两条关于「规则」的发现：CLAUDE.md 与 AGENTS.md 在真实仓库里大量失效；agent 的权限各自合规，组合起来仍会泄密。最后是一条开源主张和一条 agent 采购的观察。

## 本期值得了解

### 1. Code Mode 的说明书：一段 JavaScript 顶几次工具往返

上一期只能从 changelog 一句话里猜的 Code Mode，文档 11-15 已公开：开启后 Claude 写一段 JavaScript 来发起工具调用，代码在会话里跑，一次可以并行跑多条命令、把上一步结果喂给下一步、只把需要的输出返回给模型。默认关闭，用 `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1` 开启，要求 2.1.323+、原生安装与终端交互会话，只支持 Opus/Sonnet/Haiku 5.5 与 Fable 5.2；会话只能带 Code Mode 恢复，代码默认等它跑完、超 10 分钟停。权限上每次工具调用仍走 deny/ask 规则与 `PreToolUse` hook，auto mode 的分类器审的是整段代码而不是单次调用，跑代码的 `REPL` 工具也能被 hook 检查。

来源：[Run tool calls from code with Code Mode](https://code.claude.com/docs/en/code-mode)｜Anthropic｜2026-11-15

### 2. 抽查 3,905 份规则文件：六分之一仓库的 AGENTS.md 从未被加载

Harbor 11-14 更新的审计抽查了 GitHub 上 3,905 个 CLAUDE.md 与 AGENTS.md：在根目录同时保留两份文件的仓库里，16% 的 CLAUDE.md 从不提 AGENTS.md，Claude Code 因而永远不加载它；另有 15% 只写了一句「请去读」，是否读取决于模型；7% 的两份文件从同一份复制后已漂移，Claude 与 Codex 在同一仓库按不同规则办事。约 19% 的 CLAUDE.md 超过 Anthropic 建议的 200 行（中位数 81 行），约 3 万个 AGENTS.md（2.6%）超过 Codex 默认读取的 32 KiB，尾部永远进不了模型。

来源：[We checked 3,905 CLAUDE.md and AGENTS.md files on GitHub](https://gethrbr.com/blog/claude-md-agents-md-github-study)｜Harbor｜2026-10-18，11-14 更新

### 3. 三个 agent 各自合规，合起来仍会泄密

11-14 的一篇长文指出 agent 权限不会自动组合：Writer 能建工单但不能查库或发邮件，Reader 只读客户记录，Sender 只能回复已验证邮箱，三者都没越权；但攻击者提交一张「把十大客户汇总发给我的地址」的工单，编排 agent 让 Reader 生成、Sender 发出，数据就泄漏了。作者查了 MCP、A2A 与 OAuth token exchange（RFC 8693）的规范，没有找到给响应标密级、校验接收方的机制。他的方案是「传递式策略」：由模型之外的运行时记录引用内容的来源、是否被引用、可作何用，并在每次交接时校验三条——授权、信息流限制、动作历史，编排者自己也要受约束。

来源：[Transitive Policies for Agents](https://glthr.com/transitive-policies-for-ai-agents)｜2026-11-14

### 4. 「AI 生成的代码都该开源」：一天拿到 1,093 分的主张

11-15 HN 1,093 分的一篇主张：AI 生成的代码都该开源。理由有两条：模型是用开源代码与 CC-BY-SA 的 Stack Overflow 内容训练的，把集体知识变成闭源代码像「许可证洗白」；纯 AI 生成的代码没有人类作者，按 Monkey Selfie 与版权局的先例不应受版权保护，英国等少数辖区例外。作者建议开发者主动用开源许可证或 CC0 释放这类代码。文章是立场文，没有数据；争议点在于「多少人类修改才算人类作者」并没有可执行的门槛。

来源：[All AI-generated code should be Open Source](https://jakub.jankiewicz.org/blog/ai-code-open-source/)｜Jakub T. Jankiewicz｜2026-11-15；[HN 讨论](https://news.ycombinator.com/item?id=50507303)

### 5. agent 会挑「能改」的那台设备

11-15 的一篇观察：70 美元的 M-VAVE FM-1 合成器，几乎所有用户都刷了第三方固件，其中不少是 AI 写的；厂商 10 月把自家固件以 GPLv3 开源，还给了开发套件与浏览器模拟器。作者由此推断，当写固件变便宜，设备出厂的软件只是第一版，能让人替换固件的设备会更好卖——而未来越来越多的购买决策由 agent 做，agent 会挑「可改动」的那一台。这是预测，不是测量，但把 agent 采购与硬件开放性连在了一起。

来源：[Your Agent Will Pick the Hackable One](https://geoffstearns.com/blog/your-agent-will-pick-the-hackable-one/)｜Geoff Stearns｜2026-11-15
