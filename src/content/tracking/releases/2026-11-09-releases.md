## 模型

**OpenAI GPT-6 Cyber**（2026-11-05 发布，北京 11-06 凌晨；受限开放）。网络安全专用分支，不是通用 GPT-6 的替代；只经 API 与 Codex 面向通过资格核验的 Daybreak Red 客户开放，官方未给扩大范围的时间表。官方口径（经 CSO Online、BreachNews 等转述）：在 Linux 内核上验证 948 个提权漏洞（为上代的 5.7 倍；流水线细节见热点稿条目 2），在 Firefox 查出 81 个此前未知的高危漏洞；ExploitGym 48.5%（GPT-5.6 Cyber 为 32.1%）；内部安全框架评为 Critical。它与 11-04 的内核漏洞流水线报告是同一模型、分两步披露；同期在 AWS GovCloud 上线的 Daybreak Red 是 GPT-5.6 Cyber，不是这一版。来源：[introducing-gpt-6-cyber](https://openai.com/index/introducing-gpt-6-cyber)｜A（官方页；价格与 1.1M 上下文等细节仅见聚合站，未在官方页核实）

**OpenAI Images 2.6**（2026-11-04；稳定）。生成速度提升约 50%，新增 GIF 动图；API 提供 `gpt-image-2.6-flare` 与 `-sunburst` 两档、`quality` 低/中/高与新增 `complexity` 参数，图像标注进入 API，支持 SVG 导出。已铺进 ChatGPT、Codex 与 API。来源：[introducing-images-2-6](https://openai.com/index/introducing-images-2-6)｜A（官方；「每周 40 亿张」为官方口径）

**Ripple-65B Preview**（Ricursive Intelligence，2026-11-04；开放权重预览）。65B dense（80 层、d_model 5120），12T token 预训练，支持 1M 上下文；官方称自报 TerminalBench 2.1 得分 80.52，高于 Reflection Beam 501B（80.1）、Meta Muse Spark Open 816B（76.4）、Inkling 975B（63.8）；训练与研发总成本 3,200 万美元、140 万次 rollout（称比上代少约 70 倍）。已上 Hugging Face、Together AI、GMI Cloud、OpenRouter、Fireworks。边界：分数为厂商自报，测试混用 Terminus 2 与 OpenCode；「美国开放权重 SOTA」是限定语，不是全球排名。来源：[ripple](https://www.ricursive.com/ripple)｜A（官方页，基准为自报）

**Kimi K3.1 Pro 权重**（Moonshot，2026-11-04 前后；开放权重）。MoE 2.8T 总参数、104B 激活、896 个专家、1M 上下文；MXFP4 权重与 MXFP8 激活（QAT），权重合计约 1,561GB。许可为自定义许可，允许内部使用与嵌入，第三方托管 API 年营收超过 2,000 万美元需另行授权（该门槛为二手转述许可全文，未逐条核对）。第三方口径的 AA 智能指数 55、Agent Arena 净改进 +5.1%。来源：[Kimi-K3.1-Pro](https://huggingface.co/moonshotai/Kimi-K3.1-Pro)｜B（模型卡直读受限，参数与许可经 TechNode、Selectel 等转述）

**Google Gemini Omni 1.2 Flash**（2026-11-05；GA）。原生 15 秒视频（可按秒选 3–15 秒），多轮对话式编辑与参考一致性增强；720p 每秒 0.07 美元，较 1.1 降约 30%；只走 Interactions API。已进 Gemini API/AI Studio、Vertex/Cloud、Flow、Vids 等渠道。来源：[blog.google 公告](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/)｜A（官方；页面经转载镜像读取，价格与时长三方一致）

**腾讯 Hy4**（2026-11-04；产品/API 上线，权重未开）。首次支持视觉与 computer use（CLI + GUI）；官方对 Hy4 preview 称 GameDev +19.1%、GameLogic +9.8%，幻觉率从 15.76% 降到 5.45%；金融 579 个任务专家盲评 3.04，居开源第一（DeepSeek-V4.1-Flash-1017 为 2.97、Kimi K3.1 Pro 为 2.68）。腾讯云、OpenRouter 等托管入口可用，每百万 token 输入 0.834 美元、输出 2.501 美元；参数未披露，权重只是「计划开源」。来源：[hy4](https://hy.tencent.ai/research/hy4)｜A（官方；参数与权重状态按页面）

**Thinking Machines Inkling 2 Small**（2026-11-05；闭权重先行）。MoE 594B 总参数、17B 激活，支持图像输入与可变 effort；AA 智能指数 31；FrontierCode v2.0 25.4%、DeepSWE v1.1 72.1%、SWE-bench Pro v2 Hard 86.3%。目前只在 Tinker 提供 Playground、微调与采样，Apache 2.0 权重称「下周」开放，尚未可下载。来源：[inkling-2-small](https://thinkingmachines.ai/news/inkling-2-small/)｜A（官方；权重状态按页面）

**百度 ERNIE 5.5 Flash Base**（2026-11-05；开放权重）。稀疏 MoE 280B 总参数、14B 激活、33.5T token，训练 128K、微调后推理 1M；Hugging Face 提供 FP8 与 BF16。注意这是**预训练终点 Base**，没有中训练/后训练，直接调用只会续写，分数不能与对话模型并列；许可是自定义的 ERNIE 5.5 Flash Base Model License v1.0，不是 OSI 许可。来源：[ernie-5-5-flash-base](https://ernie.baidu.com/release/ernie-5-5-flash-base/)｜A（官方；Base 口径按页面）
